# Für die Hausverwaltung

Dieser Bereich richtet sich an das Hausverwaltungs-Team: Wer den laufenden Betrieb im Blick
behalten, Sensordaten und Logs einsehen oder bei einer gemeldeten Störung nachschauen möchte,
findet hier die Zugänge und Dashboards. Für die allgemeine Erklärung, wie die Heizung
funktioniert, siehe [Für Nutzer:innen](/docs/nutzer).

- [Grafana-Dashboards](/docs/hausverwaltung/grafana) — Sensordaten, Zustände und Logs live und im
  Verlauf
